            What can I use?
            
          
              
          Rules are plain English. The app compiles them once; matching runs on every import or Apply.
          
              
          When (conditions — all must match)
          
              
            
                
          • Generated Description — merchant/payee label (recommended)
            • 
                
          • Description — any description text (Generated, Original, Simple, User)
            • 
                
          • Amount — exact dollar value only (sign ignored; 9.99 matches -9.99)
            • 
              
          
              
          Text patterns: exact text, *contains*, prefix*, *suffix. Multiple amounts or merchants can be OR’d in hand-written rules.
          
              
          Not supported as conditions: category, classification, flow type, date, or amount ranges (>, <, between).
          
              
          Then set (optional fields)
          
              
            
                
          • AI Category, AI Sub-category
            • 
                
          • Classification (Personal / Business)
            • 
                
          • Flow Type (Expense / Income / Transfer / Adjustment)
            • 
                
          • Type (Fixed / Variable), Budget Tier (Need / Want / Wish / Review)
            • 
                
          • Category (bank), Sub-Type
            • 
              
          
              
          Examples
          
              
          Simple (use the builder below or type directly):
          
              
          If Generated Description is Merchant A and Amount is 9.99, set AI Category to Category X, Classification to Business, Flow Type to Expense
          
              
          More complex (type in the composer — builder cannot express OR on original description, parentheses, etc.):
          
              
          If Generated Description contains Vendor A and (original description contains 'ACCT1' OR original description contains 'ACCT2') and Amount is 100, set Flow Type to Transfer, AI Category to Category X, AI Sub-category to Sub Y, Classification to Personal
          
              
          Complex rules still compile via the LLM; the matcher supports them when the compiled JSON matches the engine (see roadmap for future column-specific and range conditions).

              Approve — Apply the proposal: confirm labels, fix audit flags, open Custom Rules with preview, review cadence, or open AI Rules for category renames.

              For label queue items, Reject and Cancel both keep the merchant in the inbox until you confirm labels.
